## Что такое Золотое Яблоко

**Золотое Яблоко (Gold Apple)** — один из крупнейших российских мультибрендовых ритейлеров косметики, парфюмерии и товаров для красоты. Работает в форматах:
- Оффлайн-магазины (преимущественно торговые центры)
- Интернет-магазин goldapple.ru
- Мобильное приложение

**Основан:** Екатеринбург, 2004 год  
**Оборот (оценочно):** входит в топ-3 косметических ритейлеров РФ наряду с Л'Этуаль и Рив Гош

## Ассортимент (из URL slug-анализа)

По URL-паттернам в sitemap видны ключевые категории:

- **Макияж** (`/makijazh`): лаки, губы, дети
- **Уход** (`/uhod`): уход за лицом, патчи, маски
- **Парфюмерия** (предположительно `/parfyumeriya`)
- **Бренды**: La Roche-Posay, Argabeta, отдельные бренд-страницы
- **Взрослые товары**: `*adultonly-*` blocked — эротическая парфюмерия или 18+

## Главный вывод для SEO-стратегии

Золотое Яблоко — крупнейший каталог с ~490,000 URL на Magento 2. Ключевые риски:
1. **Plaid WAF**: потенциально блокирует поисковых ботов если Yandex/Google IP попадают в blocklist
2. **Масштаб без качества**: ни один из 147,000 проанализированных URL не содержит `<image:image>` тегов в sitemap — огромная потеря для Яндекс.Картинки
3. **Блокировка коммерческих страниц** (loyalty, сертификаты) — потеря трафика на транзакционных запросах
