## Анализ URL-паттернов по семантическим кластерам

### Кластер 1: Макияж

Из sitemap: `/makijazh`, `/makijazh/nogti/lak-dlja-nogtej`, `/makijazh/detjam/guby`

**Структура глубины:**
```
/makijazh                               → «макияж купить»
├── /makijazh/nogti                     → «лаки для ногтей»
│   └── /makijazh/nogti/lak-dlja-nogtej → «лак для ногтей купить»
└── /makijazh/detjam                    → «детская косметика»
    └── /makijazh/detjam/guby           → «детские помады/блески»
```

**SEO-наблюдение:** Глубина 3 уровня с описательными слагами — хорошо для long-tail семантики.

### Кластер 2: Уход за лицом

Из sitemap: `/uhod/uhod-za-licom/patchi`

```
/uhod                                   → «уход за кожей»
└── /uhod-za-licom                      → «уход за лицом»
    └── /uhod/uhod-za-licom/patchi      → «патчи для глаз купить»
```

### Кластер 3: Брендовые страницы (/s/)

Паттерн `/s/brand-name` — 540 URLs в sitemap-1:
- `/s/la-roche-posay-anthelios` — La Roche-Posay SPF-линейка
- `/s/naturella-normal` — Naturella

**Интерпретация:** Это branded landing pages — страницы под конкретные серии брендов. SEO-стратегия захвата трафика по запросам «[бренд] [серия] купить».

### Кластер 4: Фильтровые лендинги (/f/)

Паттерн `/f/descriptive-slug` — 2,059 URLs в sitemap-1:
- `/f/bb-krem-korea` — «BB крем Корея»
- Предположительно: `/f/tonik-dlya-lica`, `/f/krem-ot-morshhin` и т.д.

**Интерпретация:** Это SEO-лендинги под фасетные фильтры. Вместо параметрического URL `?brand=xxx&type=bb` — чистый URL `/f/bb-krem-korea`. Это правильная архитектура для фасетной навигации.

## Анализ URL-слагов — качество SEO-тексторий

### Товарные URL

Паттерн: `/SKU-brand-product-name`  
Примеры:
- `/19000044609-argabeta-5-fiber-shine-paste`
- `/19000069280-awakening`
- `/24100100017-vitamino-color-a-ox`

**Плюсы:**
- SKU обеспечивает уникальность без конфликтов
- Продуктовое название в slug — контекст для ботов

**Минусы:**
- Числовой SKU в начале URL снижает информативность первых символов
- Нет категории в URL товара (`/makijazh/19000044609-...`) — сложнее понять контекст из URL
- Некоторые слаги — транслитерация названий (не оптимизированы под русские запросы)

### Категорийные URL

Транслитерация: `lak-dlja-nogtej`, `uhod-za-licom`, `patchi` — читаемо и логично.  
Отсутствие `.html` суффикса — правильное решение для Magento 2 в 2024+.

## Семантическая стратегия: /f/ vs /s/ страницы

### /f/ — Filter-based landing pages
**Стратегия:** URL `/f/bb-krem-korea` создаётся под запрос «BB крем Корея купить». Это классический подход к фасетной SEO-оптимизации.

**Риск:** 2,059 фильтровых URL только в одном sitemap. К sitemap-10 их может быть 20,000+. При низком качестве контента — риск тонкого контента.

### /s/ — Search/Brand landing pages
**Стратегия:** URL `/s/la-roche-posay-anthelios` — лендинг под брендовый поиск «La Roche-Posay Anthelios купить».

**Преимущество:** Захватывает трафик по конкретным сериям и линейкам брендов — очень ценный коммерческий трафик.
