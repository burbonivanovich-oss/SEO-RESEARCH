# Этап 8: Анализ профиля обратных ссылок — Золотое Яблоко
**Дата:** 2026-04-25 | **Примечание:** Прямые данные ссылочного профиля недоступны — SemrushBot, MJ12bot, Ahrefs-бот заблокированы в robots.txt. Анализ основан на косвенных сигналах, отраслевых паттернах и публично известных партнёрствах.

---

> **Ограничение:** goldapple.ru явно блокирует крупнейшие краулеры ссылочного профиля:
> ```
> User-agent: SemrushBot → Disallow: /
> User-agent: MJ12bot   → Disallow: /   (Majestic)
> User-agent: MegaIndex → Disallow: /
> User-agent: AhrefsBot → Disallow: /
> User-agent: DataForSeoBot → Disallow: /
> ```
> Это означает, что ни один публичный SEO-инструмент не имеет полных данных о ссылочном профиле goldapple.ru. Ниже — аналитика по косвенным данным.

## 1. Известные типы доноров ссылок

### 1.1 Официальные партнёры — бренды-доноры

goldapple.ru — авторизованный ретейлер сотен брендов. Большинство брендов указывают «официальных ретейлеров» на своих сайтах:

| Тип донора | Примеры | Сила ссылки |
|---|---|---|
| Официальные бренды (EU/US) | La Roche-Posay, Vichy, Maybelline | Высокая (DR 70–90+) |
| Нишевые французские/корейские бренды | NUXE, Erborian, Missha | Средняя |
| Российские бренды (отечественные) | Natura Siberica, Belita | Средняя |
| Агрегаторы «где купить» | irecommend.ru, otzovik.com | Средняя |

**Потенциал:** Если у goldapple есть страница `where-to-buy` или прямой листинг на бренд-сайтах — это несколько сотен высококачественных ссылок.

### 1.3 СМИ и beauty-медиа

goldapple.ru регулярно упоминается в:

## 2. Структурный анализ внутренних ссылок

На основе sitemap URL-структуры:

### Иерархия внутренней перелинковки

```
Главная (/)
├── /makijazh           ← топ-категория
│   ├── /makijazh/nogti        ← подкатегория
│   │   └── /makijazh/nogti/lak-dlja-nogtej  ← subcategory
│   │       └── /19000XXXXX-product          ← товар
│   └── /makijazh/detjam
├── /uhod
├── /brands
│   └── /s/la-roche-posay-anthelios  ← бренд-лендинг
├── /f/bb-krem-korea                 ← фильтр-лендинг
└── /blog
```

### Потенциальные разрывы в перелинковке

| Проблема | Риск |
|---|---|
| Блог НЕ ссылается на категории (предположительно) | Потеря PageRank с информационных страниц |
| `/f/` страницы не связаны с `/s/` страницами | Разрозненные ссылочные кластеры |
| Заблокированные разделы (`/sertifikaty`) | «Мёртвые» PageRank ветки |
| SKU-товары без breadcrumb schema | Слабая сигнализация иерархии |

## 4. Риски ссылочного профиля

### Типичные риски e-commerce beauty

| Риск | Вероятность | Описание |
|---|---|---|
| Купленные ссылки из прошлого | Средняя | Активный e-commerce в 2010-х часто применял закупку |
| Дорвей-трафик через партнёрки | Средняя | CPA-партнёрки (`subid`, `rb_clickid` в Clean-param) |
| Спам-ссылки с каталогов | Высокая | Автоматические каталоги ссылаются на крупные магазины |
| Ссылки с заблокированных сайтов | Низкая | Санкции могут затронуть бывших партнёров |

### Признак качества ссылочной стратегии

Наличие в robots.txt `Clean-param: rb_clickid` и `af_prt` говорит об активных CPA-сетях. Партнёрские программы часто генерируют как ценные ссылки (качественные контентные сайты), так и спам (купонные сайты).
