# Этап 4а: Анализ посадочных страниц — Золотое Яблоко
**Дата:** 2026-04-25 | **Примечание:** HTML-страницы недоступны из-за Plaid WAF. Анализ основан на URL-структуре (sitemap), robots.txt, challenge page HTML и типологии Magento 2.

---

> **Ограничение:** Без доступа к HTML не удаётся проверить meta-теги, H1, schema, alt-теги. Анализ структурных и архитектурных аспектов — на основе доступных данных. Каждый пункт помечен источником.

---

## Типология посадочных страниц

### 1. Главная страница (/)

**Тип:** Бренд-хаб + каталог-навигатор  
**Ожидаемые элементы (Magento 2 standard):**
- Слайдер с акциями
- Категорийная навигация
- Промо-блоки
- Блок «новинки» / «хиты продаж»

**SEO-риски (типичны для Magento 2 e-commerce):**
- JavaScript-heavy homepage (React/Vue поверх Magento)
- Плаид-challenge потенциально блокирует первый проход YandexBot
- Нет данных о meta description, H1, schema

**Наблюдение из challenge page HTML:**
```html
<html lang="en" translate="no">
```
Главная страница возвращает challenge с `lang="en"` — не `lang="ru"`. Если реальная страница также использует `lang="en"`, это сигнальная ошибка для Яндекса (ожидается `lang="ru"` для российского e-commerce).

---

### 2. Товарная карточка (/SKU-slug)

**Масштаб:** ~400,000 страниц (основной тип в sitemap)  
**URL-паттерн:** `/19000044609-argabeta-5-fiber-shine-paste`

**Ожидаемые SEO-элементы:**
- Title: `[Название товара] [Бренд] купить — Золотое Яблоко`
- H1: название товара
- Описание, состав, применение
- Цена (для Product schema)
- Отзывы покупателей
- Хлебные крошки (BreadcrumbList)

**Выявленный риск из sitemap:**
- В sitemap **нет image:image тегов** несмотря на объявленный namespace
- `changefreq: daily` для 400,000 товаров — неправдоподобно (цены меняются, но не ежедневно у всех)
- `priority: 1.0` для всех товаров одинаково — нет дифференциации «хитов» от «аутсайдеров»

**Типичные проблемы Magento 2 товарных страниц:**
- Дублирование description в meta (одинаковый шаблон)
- Без schema `Product` + `AggregateRating` — нет звёзд в SERP
- Изображения без alt-текста (при большом каталоге часто упускают)

---

### 3. Категорийные страницы (/category/sub/sub2)

**Масштаб:** ~10,000 страниц (оценочно)  
**Пример:** `/makijazh/nogti/lak-dlja-nogtej`

**SEO-потенциал:**
Категорийные страницы — главные донеры трафика e-commerce. Запросы вида «лак для ногтей купить», «лаки для ногтей цена» — транзакционные ВЧ.

**Структурные наблюдения из robots.txt:**
```
Disallow: /catalog/category/view/   (старые Magento-пути)
Disallow: /catalog/product_compare/
```
Чистые URL категорий типа `/makijazh/nogti` не заблокированы — корректно.

**Типичные проблемы:**
- SEO-текст под категорию (100–300 слов) часто отсутствует или шаблонный
- Пагинация: `?p=2` заблокирована Googlebot (`/*?*`) — Google не индексирует страницы 2+
- Фасеты: если `/f/` не покрывает все популярные фильтры — трафик теряется

---

### 4. Фильтровые лендинги (/f/slug)

**Масштаб:** ~6,000 страниц (оценочно)  
**Пример:** `/f/bb-krem-korea`

**Стратегическая ценность:** Это один из наиболее умных SEO-решений на сайте. Вместо URL с параметрами (`?brand=korea&type=bb-krem`) — чистый описательный slug.

**Потенциальные проблемы:**
- **Тонкий контент:** если страница содержит только товарную сетку без уникального текста — риск
- **Нет данных о H1:** предположительно «BB крем Корея» — это хорошо, но нужно проверить
- **Дублирование:** если `/f/bb-krem-korea` и `/makijazh?type=bb&country=korea` оба существуют — конфликт canonical

---

### 5. Брендовые лендинги (/s/slug)

**Масштаб:** ~1,800 страниц (оценочно)  
**Пример:** `/s/la-roche-posay-anthelios`

**SEO-стратегия:** Захват запросов «[бренд] [линейка]». Очень ценный коммерческий трафик — пользователи, знающие конкретный бренд+серию, готовы к покупке.

**Риски:**
- Без уникального контента о серии — поисковик может считать страницу тонкой
- Нужна схема BreadcrumbList: `Главная → Бренды → La Roche-Posay → Anthelios`

---

### 6. Страница брендов (/brands)

**Тип:** Бренд-хаб, алфавитный указатель  
**SEO-потенциал:** Запросы «косметика [бренд] купить», «все бренды золотое яблоко»

**Ожидаемый контент:** Алфавитный список брендов со ссылками на `/s/brand-name`

---

### 7. Блог (/blog)

**Тип:** TOFU-контент (информационный трафик)  
**Не индексируется?** `/blog` не упомянут в robots.txt как заблокированный → должен индексироваться

**SEO-потенциал:** Статьи о красоте и уходе могут занимать топ по информационным запросам («как выбрать тональный крем», «лучшие BB-кремы») и конвертировать в покупку.

---

## Типичные Magento 2 SEO-проблемы (применимы к goldapple.ru)

| Проблема | Вероятность | Влияние |
|---|---|---|
| Одинаковый шаблонный meta description для тысяч товаров | Высокая | 🔴 |
| Отсутствие Product schema с AggregateRating | Средняя | 🔴 |
| Дублирование контента: /catalog/product/view/id/XXX vs /slug | Низкая (заблокировано) | — |
| Пагинация /category?p=2 заблокирована для Googlebot | Подтверждено | 🟡 |
| Изображения без alt-тегов (масштаб 400k товаров) | Высокая | 🔴 |
| Хлебные крошки без BreadcrumbList schema | Средняя | 🟡 |
| Медленная загрузка из-за JS-heavy frontend | Высокая | 🟡 |

## Приоритеты для проверки

| # | Что проверить | Метод |
|---|---|---|
| 1 | `lang` атрибут на реальных страницах (не challenge) | Browser DevTools / Яндекс.Вебмастер |
