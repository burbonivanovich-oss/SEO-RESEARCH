## Позиционирование бренда

### Заявленное позиционирование (публичное)

**Золотое Яблоко** позиционируется как:
> «Многоформатный ритейлер красоты с широким ассортиментом нишевых и массмаркет брендов, сочетающий физические магазины с цифровыми сервисами»

Особенности:
- Сильный акцент на нишевые и западные бренды (в отличие от Л'Этуаль с более масс-маркет корзиной)
- Позиционирование как «эксперт красоты», а не просто ритейлер
- Блог + экспертный контент как инструмент E-E-A-T

### Технологическое позиционирование (из Clean-param)

Детальность tracking-параметров в robots.txt раскрывает зрелость маркетинговой инфраструктуры:

| Трекер | Параметры | Вывод |
|---|---|---|
| AppsFlyer | `af_adset_id`, `af_c_id`, `af_channel`, `af_prt` | Активный мобильный маркетинг, партнёрские программы |
| Mindbox | `mindbox-click-id` | CRM-персонализация, email/push |
| Calltouch | `calltouch_tm` | Отслеживание звонков |
| Callibri | `callibri` | Мультиканальная аналитика |
| Facebook/Meta | `fbclid` | Таргетированная реклама |
| Google Ads | `wbraid`, `gbraid`, `gclid` | Performance Max, Search |
| Яндекс | `yclid`, `ychid`, `etext` | Яндекс.Директ |
| Affiliate | `subid`, `sub_id`, `sub_id3`, `rb_clickid` | CPA-партнёрки |

**Вывод:** Золотое Яблоко — технологически зрелый e-commerce с полным спектром digital-маркетинга. Это означает серьёзную конкуренцию за платный трафик, что делает органический SEO-трафик ещё более ценным (нет CPA-комиссии).

## Анализ УТП через призму SEO-страниц

### Что раскрывают URL-паттерны

| УТП | Как реализован в структуре | SEO-эффект |
|---|---|---|
| **Нишевые бренды** | `/s/brand-series` страницы (~1,800 URL) | Захват branded трафика |
| **Широкий ассортимент** | ~400,000 товарных страниц | Длинный хвост |
| **Программа лояльности** | `/loyalty` + `/reward-points` (заблокирован!) | ❌ SEO не работает |
| **Подарочные карты** | `/sertifikaty` (заблокирован!) | ❌ SEO не работает |
| **Экспертный контент** | `/blog` (доступен) | ✅ TOFU трафик |
| **Акции/скидки** | `/private-sales` (заблокирован!) | ❌ SEO не работает |
| **B2B** | `/b2b/` (частично заблокирован) | ⚠️ Ограниченный |
| **Взрослая категория** | `*adultonly-*` (заблокирован) | — Намеренно |

**Ключевой парадокс:** Три из четырёх главных конверсионных УТП (лояльность, сертификаты, распродажи) заблокированы от индексации. Пользователи, которые ищут эти продукты, не находят goldapple.ru в органике.

## Конверсионная воронка (TOFU → MOFU → BOFU)

### TOFU — Осознание потребности

**Покрытие:** `/blog` — информационный контент  
**Примеры запросов:** «как выбрать тональный крем», «лучшие бренды SPF», «BB крем vs тональный»

**Сильные стороны:**
- Блог существует и индексируется
- `/s/la-roche-posay-anthelios` — это TOFU/MOFU гибрид (пользователь видел рекламу линейки)

**Слабые стороны:**
- Неизвестно качество блог-контента без HTML
- Нет данных о внутренних ссылках блог → каталог

### MOFU — Рассмотрение вариантов

**Покрытие:**
- `/brands` — обзор брендов ✅
- `/s/brand-series` — сравнение внутри бренда ✅
- `/f/filtered-query` — фильтровые лендинги ✅

**Хороший пример:** `/f/bb-krem-korea` — пользователь ищет BB крем корейского производства, получает кураторскую подборку → MOFU.

### BOFU — Принятие решения

**Покрытие:**
- `/category/sub` — категорийные страницы ✅
- `/SKU-slug` — товарные карточки ✅
- `/sertifikaty` — ❌ ЗАБЛОКИРОВАН
- `/checkout/` — ❌ ЗАБЛОКИРОВАН (правильно)

**Проблема BOFU:** Страница акций и скидок (`/private-sales`) заблокирована. Пользователь с запросом «золотое яблоко скидки» не находит органический результат.
