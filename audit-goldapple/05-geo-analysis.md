## 2. AI-краулеры: критическая проблема

### Статус в robots.txt

В robots.txt goldapple.ru **нет ни одного упоминания** AI-краулеров:

| Бот | Упомянут? | Раздел | Статус |
|---|---|---|---|
| GPTBot (OpenAI) | ❌ НЕТ | → User-agent: * | Ограничен `Disallow: /*.html` (но .html не используется) |
| ClaudeBot (Anthropic) | ❌ НЕТ | → User-agent: * | Аналогично |
| PerplexityBot | ❌ НЕТ | → User-agent: * | Аналогично |
| Google-Extended | ❌ НЕТ | → User-agent: * | Аналогично |
| CCBot (Common Crawl) | ❌ НЕТ | → User-agent: * | Аналогично |

**Вывод по robots.txt:** AI-боты не заблокированы явно (поскольку `/*.html` для `*` не влияет на реальные URL). Они могут теоретически индексировать сайт по robots.txt.

### Критический барьер: Plaid WAF

Это реальная блокировка AI-краулеров:

```
goldapple.ru → Plaid challenge ("checking device")
→ fetch('/web/api/v1/settings') → 403 для datacenter IP
→ AI-краулер видит страницу "checking device", не контент
```

**Все крупные AI-системы краулят с datacenter IP:**
- ChatGPT (OpenAI): Microsoft Azure IP ranges
- Perplexity: AWS IP ranges
- Claude (Anthropic): AWS IP ranges
- Google (AI Overviews): Google datacenters

Если `goldapple.ru/web/api/v1/settings` возвращает 403 для этих IP-диапазонов, все AI-поисковики видят только:
```html
<title>Gold Apple — checking device</title>
<body>Упс! В вашем браузере не включён JavaScript</body>
```

**Это означает, что goldapple.ru фактически невидим для всех AI-поисковиков кроме Яндекс Нейро** (если Yandex IP whitelisted).

## 3. Яндекс Нейро — специфика

Яндекс Нейро использует YandexBot для сбора данных. Поскольку реальный YandexBot краулит с Yandex datacenter IP, а не с Azure/AWS, он вероятно проходит через Plaid challenge (если Yandex IP в whitelist).

**Что Нейро может цитировать с goldapple.ru:**
- Названия и описания товаров (если не за challenge)
- Статьи блога
- Категорийные описания

**Что Нейро НЕ получает:**
- Структурированные данные (нет llms.txt)
- Четкое описание бренда
- Контекст о программах лояльности (заблокированы)

## 4. Конкретные AI-запросы и вероятные результаты

### «Какой крем для лица выбрать?»
- **Текущее:** goldapple.ru, скорее всего, не цитируется (challenge или нет экспертного HTML-контента в нужном формате)
- **Потенциал:** огромный — если блог правильно оптимизирован

### «Где купить La Roche-Posay в России?»
- **Текущее:** неизвестно, Яндекс Нейро может цитировать из Маркета
- **Потенциал:** `/s/la-roche-posay-anthelios` с правильным SSR контентом

### «Что такое BB крем?»
- **Текущее:** вряд ли goldapple.ru — нужны информационные страницы
- **Потенциал:** статьи блога + `/f/bb-krem-korea` с экспертным вводным текстом
