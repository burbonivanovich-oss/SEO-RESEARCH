## Косвенные сигналы ссылочного профиля

### Сигналы высокого авторитета

**1. Материнский домен kontur.ru**
Kontur.ru — один из крупнейших российских b2b IT-ресурсов. Сайт входит в топ-500 российских доменов по посещаемости. Все страницы Контур.Маркет (`kontur.ru/market/*`) наследуют Domain Authority материнского домена.

**2. Включение в реестр Минцифры**
URL `reestr.digital.gov.ru/reestr/309893/` — официальная страница в государственном реестре ПО. Это означает обратную ссылку с `.gov.ru` домена — один из самых ценных ссылочных доноров для российского SEO.

**3. Аккредитация ОФД**
ОФД должны быть аккредитованы ФНС России. Наличие в реестре ФНС подразумевает упоминание/ссылку с налог.ru домена.

**4. Бренд SKB Kontur**
Kontur.ru активно упоминается в деловых СМИ (РБК, Ведомости, Коммерсант), партнёрских материалах, обзорах ПО. Это создаёт органический ссылочный фон для всех под-продуктов включая Контур.Маркет.

## Анализ внутренней ссылочной структуры

### Распределение внутренних ссылок по страницам

| Страница | Внутренних ссылок | Уникальных URL |
|---|---|---|
| /market | 80 | ~46 |
| /features | 98 | ~65 |
| /kkt | 101 | ~68 |
| /ofd | 74 | ~36 |
| /responses | 79 | ~37 |
| /gossistemy | 79 | ~39 |

**Наблюдение:** Все страницы имеют примерно одинаковое количество внутренних ссылок — это признак **шаблонной навигации** (хедер + футер + сайдбар генерируют 70–80% ссылок на всех страницах). Уникальные контентные ссылки — меньшая часть.

### Проблема: /market не является хабом

Главная страница должна быть главным донором PageRank для дочерних страниц. Однако из-за JS-рендеринга ссылки с /market на /market/kkt, /market/ofd, /market/gossistemy находятся в JS и **не передают PageRank через Google**.

Яндекс обрабатывает JS лучше, но также с задержкой. Рекомендуется добавить статические HTML-ссылки в основную навигацию.

### Страницы без прямых входящих внутренних ссылок из HTML

По результатам анализа, страницы продуктов связаны преимущественно через JS-навигацию. В статическом HTML ни одна из страниц не ссылается явно друг на друга в контентных блоках (за исключением футера).

## Риски ссылочного профиля

### 1. Дублирование PageRank через редиректы
- `/market/features` → `/market/capabilities/roznitsa`
- `/market/ofd` → `/market/ofd-directoru`

Внешние ссылки на старые URL передают PageRank через 301 — теоретически сохраняется, но лучше исправить входящие ссылки на финальные URL.

### 2. Ссылки из /market/responses (23 внешних)
Нужно проверить: если это `dofollow` ссылки на агрегаторы отзывов — это нормально. Если на рекламные или нерелевантные сайты — риск пессимизации.

### 3. JS-ссылки не передают PageRank
Внутренние ссылки из JS-компонентов (каталог касс, навигация) не учитываются до второго прохода индексатора. Рекомендуется критические ссылки дублировать в HTML.

## Инструменты для полного анализа (рекомендуется)

После получения доступа к внешним API:

```bash
# Moz API (бесплатный план)
curl "https://lsapi.seomoz.com/v2/url_metrics" \
  -u "MOZACCESSID:MOZSECRETKEY" \
  -d '{"targets":["kontur.ru/market"]}'

# Bing Webmaster Tools (требует верификации сайта)
# → Search Performance → Inbound Links

# Ahrefs (платный) — наиболее полная база для РФ
# Site Explorer → kontur.ru/market → Backlinks

# Яндекс.Вебмастер (бесплатно, если есть доступ)
# → Внешние ссылки → Ссылающиеся домены
```

**Минимальный бесплатный аудит** — через Яндекс.Вебмастер (если есть доступ к аккаунту). Яндекс.Вебмастер показывает индексируемые обратные ссылки в своей базе — для ru-сегмента точнее Moz/Ahrefs.
