# Этап 4б: Позиционирование, УТП и конверсионная воронка — Контур.Маркет
**Дата:** 2026-04-25 | **Методология:** Анализ заголовков, CTA, текстов, ценообразования

---

## Текущее позиционирование

### Заявленное позиционирование (из H1 и мета)
> «Сохраняем ваше спокойствие в работе с кассой и госсистемами»

Это **эмоциональное позиционирование** через снятие страха: предприниматель боится штрафов, проверок, ошибок с госсистемами. Контур.Маркет — «щит» от регуляторного стресса.

### Фактическое позиционирование (из структуры продукта)
**«Всё-в-одном для МСБ»** — касса + ОФД + ЕГАИС + Честный Знак + Меркурий + учёт в одном интерфейсе.

### Разрыв между заявленным и фактическим
На главной H1 про «спокойствие», а meta description — про «автоматизацию» и «зарабатывайте больше». Два разных послания конкурируют. Пользователь на главной не понимает: это про страх или про рост?

### УТП которые есть, но плохо выражены

**«Продаём чужие кассы + даём своё ПО»** — уникальная бизнес-модель агрегатора. Пользователь покупает кассу и сразу получает экосистему. Это нигде явно не артикулировано как позиционирование.

**«Единый интерфейс для ЕГАИС + Честный Знак + Меркурий»** — в H1 /gossistemy упоминается, но не подчёркивается насколько это редкость. Конкуренты обычно закрывают одну-две системы.

**«Данные о продажах автоматически попадают в бухгалтерию»** — упоминается в тексте /ofd, но нет H2/H3 для SEO-индексации.

### УТП которых нет, но должны быть

| Отсутствующий УТП | Обоснование |
|---|---|
| Гарантия на кассы | Конкуренты указывают срок гарантии — у Контур.Маркет не найдено |
| SLA поддержки | «24/7» без конкретики — «ответим за 15 минут» работало бы лучше |
| Количество клиентов / точек | «XX тысяч торговых точек» — нет на странице |
| Сертификации / ФНС-аккредитация | Упоминание в реестре цифрового.gov есть, но не обыгрывается |
| Кейсы с цифрами | «Сэкономили NN часов в месяц» — нет ни одного на ключевых страницах |

## Анализ конверсионной воронки

### TOFU (осознание проблемы)

**Текущий охват:** Раздел «Журнал» на главной странице — контентный маркетинг. Есть ссылки на Telegram-каналы, YouTube-канал, Дзен.

**Проблема:** Журнал физически расположен в нижней части главной страницы и в нижней части /kkt. Нет кросс-ссылок с проблемных запросов («что нужно для работы по 54-ФЗ», «как подключить ЕГАИС») на конкретные посадочные.

### MOFU (рассмотрение вариантов)

**Текущий охват:**
- /market/features — страница возможностей (но слабая)
- /market/responses — социальное доказательство
- /market/kkt — сравнение оборудования

**Проблема:** Нет страницы сравнения с конкурентами. Нет страницы «как выбрать кассу» (информационный, но с коммерческим интентом). Нет кейсов/успехов клиентов с цифрами.

### BOFU (принятие решения)

**Текущий охват:**
- Цены на кассы — в HTML /kkt ✅
- Цены на госсистемы — в HTML /gossistemy ✅
- «3 месяца ОФД бесплатно» ✅
- Формы заявок и чат ✅

**Проблема:** 
- Нет единой страницы с полным прайсом («всё в одном»)
- CTAs конкурируют друг с другом (26 уникальных на главной)
- Нет «Демоверсии» на главной (есть только на /features и /ofd)

## Анализ CTA-иерархии

### Главная страница (/market) — 26 уникальных CTA

Проблема: слишком много опций → паралич выбора. По тепловой карте поведения пользователь, видящий 26 кнопок, кликает реже, чем при 3–5.

**Текущая иерархия CTA:**
1. «Подключиться» — главный
2. «Отправить заявку»
3. «Купить онлайн»
4. «Войти» — для существующих клиентов
5. ...и ещё 22

**Рекомендуемая иерархия:**
1. **Основной:** «Попробовать бесплатно 14 дней» (выше фолда, один)
2. **Вторичный:** «Посмотреть демо» (рядом)
3. **Третичный:** «Купить кассу» (в блоке оборудования)

### /market/ofd — лучшая воронка

Структура: Возможности → Цены → Отзывы → **«3 месяца бесплатно»** — классический SaaS flow. Лучший показатель на сайте.

### /market/kkt — коммерческая страница

Цены прямо в кнопках («Купить от 22 570 ₽») — сильно. Но нет фильтрации по типу бизнеса в HTML — пользователь вынужден просматривать 15+ моделей без сужения.

## Позиционирование vs. конкуренты

| Игрок | Позиционирование | Слабое место vs. Контур.Маркет |
|---|---|---|
| МойСклад | Учёт и склад для МСБ | Нет собственного ОФД и кассового железа |
| Эвотор | Умная касса + экосистема | Нет госсистем (ЕГАИС/Честный Знак) в одном |
| СБИС (saby.ru) | Всё для бизнеса (крупный) | Сложнее для малого бизнеса, дороже |
| Первый ОФД | Лучший ОФД на рынке | Нет кассы, нет учёта |
| Контур.Маркет | Всё-в-одном для МСБ | **Нет чёткого артикулированного позиционирования** |

**Парадокс:** Контур.Маркет объективно имеет самое широкое покрытие среди конкурентов (касса + ОФД + три госсистемы + учёт), но позиционирование размытое. Это упущенное конкурентное преимущество.

## Рекомендации по позиционированию

### Предлагаемое уточнённое позиционирование
> «Контур.Маркет — единственный сервис, где касса, ОФД, ЕГАИС, Честный Знак и Меркурий работают из одного окна»

Это конкретно, верифицируемо и отличает от конкурентов.

### Внедрение в страницы
1. **H1 главной:** «Контур.Маркет: касса, ОФД и госсистемы — всё в одном окне»
2. **Первый H2:** «Единственное решение, где ЕГАИС + Честный Знак + Меркурий работают вместе»
3. **Meta description:** упор на «одно окно» + конкретная аудитория

### Конверсионные улучшения
1. Убрать конкуренцию CTA — один главный призыв выше фолда
2. Добавить кейс/цифру в первый экран: «5 000+ магазинов работают без штрафов»
3. Добавить calculator-виджет стоимости на /market/kkt
4. /market/responses: добавить фильтрацию отзывов по типу бизнеса
