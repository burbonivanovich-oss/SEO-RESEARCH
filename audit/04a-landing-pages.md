## /market — Главная страница

### Структура контента

```
H1: Сохраняем ваше спокойствие в работе с кассой и госсистемами
├── H2: Все задачи в одном окне
│   ├── H3: Отчетность
│   ├── H3: Честный Знак
│   ├── H3: ФГИС «Меркурий»
│   ├── H3: Учетная система
│   └── H3: Увеличьте эффективность... с помощью Сегмент+
├── H2: Решения для работы по 54-ФЗ
├── H2: Готовые комплекты касс
├── H2: Законодательство без тревог
├── H2: Делимся знаниями
│   ├── H3: Увлекательные видеоролики
│   └── H3: Полезные телеграм-каналы
├── H2: Журнал
└── H2: Вы всё ещё думаете? Просто попробуйте
```

### Сильные стороны
- Логичная структура: проблема → решения → продукты → доверие → CTA
- H2 «Решения для работы по 54-ФЗ» — прямое попадание в регуляторный контекст
- Раздел «Журнал» формирует E-E-A-T сигнал экспертности

### Проблемы

**H1 — маркетинговый, не поисковый.** «Сохраняем ваше спокойствие» — нет ключевых слов. Яндекс не понимает что это страница автоматизации торговли.

**«Журнал» внизу страницы** без связи с основной семантикой — блок выглядит как вставной, не как часть E-E-A-T стратегии.

**Раздел «Сегмент+»** — перекрёстная продажа другого продукта в середине главной. Размывает фокус страницы.

**70 изображений, 70% без alt** — не только SEO-потеря, но и проблема доступности (a11y).

**Нет цен на главной** — пользователь не понимает порядок стоимости при первом касании.

### CTAs главной страницы (26 уникальных)
- «Подключиться» — основной CTA
- «Отправить заявку»
- «Купить онлайн»
- «Подробнее» (множество)

Проблема: CTAs дублируются и не имеют иерархии. Нет единого главного призыва к действию выше фолда.

## /market/features — Возможности (розница)

### Структура контента

```
H1: Для розницы
├── H3: Как Маркет помогает вести бизнес
├── H2: Упрощаем ведение бизнеса
│   └── H3: Убедитесь, что это удобно
└── H2: Вы всё ещё думаете? Просто попробуйте
```

### Проблемы — критические

**URL-редирект + слабая структура:** Страница задумывалась как «Возможности», но:
1. `/market/features` редиректит на `/market/capabilities/roznitsa`  
2. H1 «Для розницы» — не объясняет что это страница возможностей
3. Всего 2 H2 и 2 H3 — крайне бедная структура для страницы с 98 внутренними ссылками

**Meta description отсутствует** — Яндекс самостоятельно формирует сниппет из любого текста.

**906 слов DOM** — при JS-тонком контенте (5 слов без JS) — страница почти не существует для первого прохода индексатора.

**CTA-навигация вместо контента:** 18 уникальных CTA («Магазинам одежды», «Универмагам», «Автомагазинам» и т.д.) — это фактически суб-навигация по типам розниц, но подана как CTA-кнопки, а не как H2/H3 структура.

### Что страница должна делать, но не делает
- Быть хабом возможностей для розницы с подробным описанием каждого модуля
- Объяснять разницу между розницей / общепитом / услугами
- Содержать сравнительную таблицу возможностей по сегментам

### Структура контента

```
H1: Онлайн‑кассы и кассовое оборудование
├── H2: Готовые комплекты с кассами
│   ├── H3: Мобильный (от 28 447 ₽)
│   └── H3: Надежный (от 71 757 ₽)
├── H2: Онлайн-кассы и POS‑терминалы [14 позиций]
├── H2: Сканеры [3 позиции]
├── H2: Прочее оборудование [8 позиций]
├── H2: Сэкономим ваше время и силы
│   ├── H3: Настройка и регистрация кассы
│   ├── H3: Бесплатная доставка
│   └── H3: Рассрочка на 3 или 6 месяцев
├── H2: Пишем про кассы и не только [Журнал]
├── H2: Вопросы и ответы [FAQPage]
└── H2: Заявка на консультацию
```

### Сильные стороны — лучшая страница сайта

- **2167 слов** — максимальный объём контента
- **Цены** указаны прямо в CTA-кнопках: «Купить от 22 570 ₽» — сильный сигнал коммерческого интента
- **FAQPage** с 5 вопросами по 54-ФЗ — экспертность подтверждается
- **Услуги** выделены в H2: доставка, настройка, рассрочка — снимают барьеры покупки
- Связь с Журналом («Пишем про кассы») — E-E-A-T сигнал

### Проблемы

**91 изображение, 80% без alt** — у каждой кассы есть фото, но alt пустые или отсутствуют. Потеря в Яндекс.Картинки по запросам «[модель кассы] фото», «Атол 30Ф изображение».

**FAQPage ограничение** (авг 2023): блок «Вопросы и ответы» отличный — 5 вопросов с развёрнутыми ответами по ФЗ-54. Но FAQPage schema больше не даёт rich snippet для e-commerce. Рекомендуется оставить контент, заменить schema на `Product`.

**Нет фильтрации** в HTML (фильтры в JS): Яндекс не видит разбивку по типам бизнеса — потеря нишевых запросов «касса для кафе», «касса для магазина продуктов».

**Нет ссылок на карточки товаров** в HTML-форме — все ссылки на `/market/kkt/[model]` проставляются динамически.

## /market/ofd-directoru — ОФД

### Структура контента

```
H1: Оператор фискальных данных
├── H2: Возможности
│   └── H3: Убедитесь, что это удобно
├── H2: Цены на ОФД
├── H2: Вам также может быть интересно [перекрёстные продажи]
├── H2: API для крупного бизнеса и арендодателей
├── H2: Отзывы о сервисе
└── H2: Попробуйте 3 месяца ОФД бесплатно
```

### Сильные стороны
- Структура «Возможности → Цены → Доверие (отзывы) → CTA» — классическая конверсионная воронка
- H2 «API для крупного бизнеса» — уникальный раздел, нет у большинства конкурентов
- Лид-магнит «3 месяца бесплатно» — высокий конверсионный потенциал

### Проблемы

**URL: /ofd-directoru** — непрозрачный slug. При поиске «ОФД Контур» пользователь ожидает `/market/ofd`, а не `/market/ofd-directoru`. Внешние ссылки могут вести на `/ofd`, который редиректит — потеря PageRank-передачи.

**Meta description 78 символов** — слишком коротко: «Информация о возможностях и функциях оператора фискальных данных Контур.Маркет». Шаблонное, не продающее.

**H2 «Возможности» без конкретики** — нет перечисления конкретных возможностей в H3 (они в JS-рендеренных карточках).

**Раздел «Вам также может быть интересно»** — перекрёстные продажи в середине страницы: нарушает конверсионный поток.

**Цены не видны без JS** — H2 «Цены на ОФД» присутствует, но сами цифры — в JS-компоненте.

## /market/responses — Отзывы

### Структура контента

```
H1: Отзывы Контур.Маркет
└── H2: Оставьте отзыв о нас
```

### Уникальные данные страницы
- **4437 слов** — самый объёмный контент на сайте
- **136 изображений** — аватары и логотипы клиентов
- **75 найденных имён компаний/авторов** — реальные отзывы
- **23 внешних ссылки** — самое большое количество

### Критические проблемы

**Структура из 2 заголовков** для страницы с >100 отзывами — поисковик не понимает структуру. Нет разбивки по продуктам, типам бизнеса, датам.

**Нет Schema** — 537 элементов с классами `review-author`, `review-author__name`, `review-author__date` — полноценные отзывы без `Review` или `AggregateRating` разметки. Яндекс не показывает звёзды.

**Только 12% изображений с alt** — 136 аватаров/логотипов, только 16 с alt. Полная потеря в Яндекс.Картинки.

**88% изображений без alt** — критически плохо; это логотипы реальных компаний, которые могли бы индексироваться.

**Нет разбивки отзывов** по продуктам (касса vs ОФД vs госсистемы) — теряет нишевые запросы «отзывы о Контур.ОФД», «отзывы о Контур.Кассе».

**23 внешних ссылки** — нужно проверить: не утекает ли PageRank через dofollow-ссылки на сторонние ресурсы.

### Потенциал
Страница отзывов — один из самых ценных E-E-A-T сигналов. 75+ реальных клиентов, 4437 слов пользовательского контента. При правильной оптимизации может занять топ по «[название] отзывы».

## /market/gossistemy — Госсистемы

### Структура контента

```
H1: ЕГАИС, маркировка и «Меркурий» в одном окне
├── H2: Подключите госсистемы в одном тарифе или по отдельности
├── H2: Интеграции с другими сервисами
│   └── H3: Интеграция с iiko
├── H2: Тест-драйв сервиса в течение 14 дней
├── H2: Зарегистрируйтесь и получите тариф «Премиум» на 14 дней бесплатно
├── H2: Тарифы
├── H2: Докупите для других бизнес-задач
│   ├── H3: Товарный учет
│   └── H3: Кассовый модуль
└── H2: Есть вопросы? Мы ответим
```

### Сильные стороны
- H1 перечисляет все три госсистемы — хорошее покрытие по запросу «ЕГАИС Честный Знак Меркурий»
- Тарифная сетка с ценами (4 546–12 046+ ₽/год) — прозрачное ценообразование
- Лид-магниты: «14 дней бесплатно», «Тариф Премиум»
- Интеграция с iiko — конкретное конкурентное преимущество для общепита
- Файлы .docx для скачивания (прайс-листы) — сигнал B2B-аудитории

### Проблемы

**Три темы на одной странице** (ЕГАИС + Честный Знак + Меркурий) конкурируют друг с другом за разные семантические запросы. Каждая тема заслуживает собственной страницы с глубоким содержанием.

**Нет meta description и og:description** — полная потеря управления сниппетом.

**Нет Schema** — IdItemList или SoftwareApplication — упущены rich results.

**H2 «Тест-драйв»** дублирует H2 «Зарегистрируйтесь...» — два CTA-блока подряд вместо одного чёткого.

**69% изображений без alt** — интерфейсные скриншоты без описания.

## Общие выводы по посадочным страницам

### Системные проблемы (все страницы)
1. JS-стена — контент недоступен для первого прохода Яндекса
2. Изображения без alt (69–88%) — не работает Яндекс.Картинки
3. Отсутствие schema — нет rich snippets

### Лучшая страница: /market/kkt
Богатый контент (2167 слов), цены в HTML, FAQ с экспертными ответами, BreadcrumbList. Нужна замена FAQPage schema на Product.

### Худшая страница: /market/features  
Редирект → слабый H1 → нет meta desc → 5 слов без JS → нет schema. Фактически не существует для поисковика.

### Страница с максимальным потенциалом: /market/responses
4437 слов реального UGC-контента, но нулевая SEO-оптимизация. Один лишь AggregateRating schema может дать звёзды в SERP и поднять CTR на 20–30%.
