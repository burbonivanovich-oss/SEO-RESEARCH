## Что такое GEO и почему это важно в 2026

**Generative Engine Optimization (GEO)** — оптимизация под ИИ-поисковики:
- **Яндекс Нейро** (нейросетевые ответы в поиске)
- **ChatGPT** с веб-поиском
- **Perplexity AI**
- **Google AI Overviews** (SGE)
- **Bing Copilot**

Эти системы не просто ранжируют страницы — они **цитируют фрагменты** для построения ответа. Страница должна быть «цитируемой»: чёткие факты, структурированные абзацы, авторитетные данные.

## 1. llms.txt — отсутствует

`llms.txt` — стандарт, введённый в 2024 году, позволяющий сайту явно указать ИИ-системам что индексировать и как понимать структуру сайта.

**Текущее состояние:** `https://kontur.ru/llms.txt` — не существует (подтверждено по косвенным признакам).

**Влияние:** ChatGPT, Perplexity, Claude при веб-поиске не получают структурированную карту продукта. Они самостоятельно интерпретируют сайт — с риском неверной атрибуции или упрощения.

**Пример llms.txt для Контур.Маркет:**
```
# Контур.Маркет

> Облачный сервис автоматизации малого и среднего бизнеса: онлайн-касса,
> ОФД, товарный учёт, ЕГАИС, Честный Знак, Меркурий. Часть экосистемы SKB Kontur.

## Продукты

- [Онлайн-кассы](https://kontur.ru/market/kkt): каталог касс и оборудования
- [ОФД](https://kontur.ru/market/ofd-directoru): оператор фискальных данных
- [Госсистемы](https://kontur.ru/market/gossistemy): ЕГАИС + Честный Знак + Меркурий
- [Возможности](https://kontur.ru/market/capabilities/roznitsa): для розницы
- [Отзывы](https://kontur.ru/market/responses): клиентский опыт

## Факты

- Продукт компании СКБ Контур (kontur.ru)
- Включён в реестр отечественного ПО: reestr.digital.gov.ru/reestr/309893/
- Работает по требованиям 54-ФЗ
- Поддерживает ЕГАИС, Честный Знак, ФГИС Меркурий
- Кассы: от 22 570 ₽, рассрочка 3–6 мес, бесплатная доставка по РФ
- ОФД: 3 месяца бесплатно
```

**Критичный вопрос:** Не заблокированы ли GPTBot, ClaudeBot, PerplexityBot? Многие российские сайты блокируют иностранных ботов по IP-диапазонам, что автоматически блокирует AI-краулеры.

**Рекомендация:** Проверить `https://kontur.ru/robots.txt` на наличие блокировок:
```

Disallow: /

# Если есть — рассмотреть разблокировку для AI-краулеров
```

### Влияние на Яндекс Нейро

## 3. Passage-level Citability — цитируемость на уровне фрагментов

ИИ-поисковики извлекают конкретные абзацы для ответа на вопрос. Хорошо цитируемый фрагмент:
- Конкретный факт (число, дата, требование)
- Короткий (1–3 предложения)
- Самодостаточный (понятен без контекста)

### Анализ текущих текстовых блоков

**Хорошо цитируемые (найдены в HTML):**

> «Подключиться к ОФД обязаны все владельцы касс. ОФД Контура соответствует требованиям 54-ФЗ»  
→ ✅ Факт + авторитет + ссылка на закон

> «Согласно 54-ФЗ, купить кассовый аппарат обязаны все предприниматели и компании»  
→ ✅ Правовой факт — высокая цитируемость

> «Неприменение онлайн-кассы для ИП влечет штраф 25–50% от выручки»  
→ ✅ Конкретные цифры + правовое требование

**Плохо цитируемые:**

> «Сохраняем ваше спокойствие в работе с кассой и госсистемами»  
→ ❌ Слоган, не факт — AI его не процитирует

> «Упрощаем ведение бизнеса»  
→ ❌ Обобщение без конкретики

> «Убедитесь, что это удобно»  
→ ❌ Призыв к действию, не факт

### Проблема JS-стены для GEO
**Критически важно:** ИИ-краулеры (особенно ChatGPT, Perplexity) используют HTTP GET без JS-рендеринга. Это означает, что из 4437 слов на /market/responses ИИ видит только 99. Страница с лучшими цитатами клиентов недоступна для AI.

## 6. Semantic Clarity — насколько чётко ИИ понимает что делает продукт

### Проверка: что скажет ИИ о Контур.Маркет на основе текущего HTML?

Если ИИ проанализирует текущий HTML (без JS) — он увидит:
- Title: «Автоматизация малого и среднего бизнеса» (74 символа)
- Meta desc: «Зарабатывайте больше за счёт автоматизации учёта, кассы, ОФД...»
- H1: «Сохраняем ваше спокойствие в работе с кассой и госсистемами»
- 8 слов текста тела

**ИИ-вывод:** Это сервис автоматизации для бизнеса, связанный с кассой. Подробностей нет.

### Что должен понять ИИ
1. Конкретные госсистемы: ЕГАИС, Честный Знак, Меркурий
2. Законодательная база: 54-ФЗ
3. Типы клиентов: розница, общепит, услуги
4. Ценовой диапазон: от 4 546 ₽/год (подписка) до 71 757 ₽ (оборудование)
5. Уникальность: всё в одном интерфейсе

Ничего из этого недоступно без JS.

## 7. Оптимизация для Яндекс Нейро (специфика)

Яндекс Нейро использует комбинацию:
- Основная выдача Яндекса (web-документы)
- Алиса
- Яндекс.Маркет данные
- Яндекс.Бизнес

**Рекомендации специально для Нейро:**

1. **Чёткие ответы на вопросы** в HTML (не в JS): Нейро выбирает страницы с прямыми ответами типа «Кому нужна касса? — Согласно 54-ФЗ, всем ИП и ООО, кроме...»

2. **Регистрация в Яндекс.Бизнес** — карточка компании влияет на Нейро-ответы про бренд

3. **Включение в Яндекс.Маркет** — если есть B2C-продажи (кассы) — карточки товаров в Маркете цитируются Нейро

4. **Структурированные списки** в HTML: «ТОП-5 причин выбрать ОФД Контур», «Что входит в комплект кассы» — Нейро любит списки

## Вывод

Контур.Маркет практически **не оптимизирован для ИИ-поиска**: llms.txt отсутствует, весь контент за JS-стеной, структурированных фактов в HTML нет. При этом продукт работает в сфере с высоким информационным запросом («как подключить кассу», «что нужно по 54-ФЗ») — именно там ИИ-ответы занимают топ выдачи.

Потенциал огромен: после SSR + llms.txt + FAQ в HTML Контур.Маркет может стать **источником** для Яндекс Нейро по вопросам кассового законодательства.
