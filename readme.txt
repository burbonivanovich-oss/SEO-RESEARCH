SEO RESEARCH - Integrated SEO Agents
===================================

This project integrates 10 specialist SEO agents from the Agentic-SEO-Skill
repository for comprehensive website and GitHub repository optimization.

📦 CONTENTS
-----------
- 10 Specialist Agents
- 16 Sub-Skills
- 33 Supporting Python Scripts
- Complete Reference Data (Feb 2026)

🎯 AVAILABLE AGENTS
-------------------
1. Technical SEO Agent - crawlability, indexability, security, mobile
2. Content Quality Agent - E-E-A-T scoring, AI content detection
3. Performance Agent - Core Web Vitals analysis (LCP, INP, CLS)
4. Schema Markup Agent - JSON-LD detection, validation, generation
5. Sitemap Agent - XML sitemap validation and quality gates
6. Visual Analysis Agent - screenshots, responsiveness (Playwright)
7. GitHub Analyst Agent - metadata, README, community health
8. GitHub Benchmark Agent - competitor research and rankings
9. GitHub Data Agent - API fallbacks, traffic archival
10. Global Verifier Agent - deduplication and contradiction resolution

📖 DOCUMENTATION
----------------
See AGENTS_OVERVIEW.md for detailed descriptions of all agents and their capabilities.
See SKILL.md for command reference and sub-skill descriptions.

🚀 QUICK START
--------------
Place URLs you want to analyze and run the appropriate seo command:

seo audit <url>        - Full website audit
seo technical <url>    - Technical SEO analysis
seo content <url>      - Content quality & E-E-A-T
seo schema <url>       - Schema markup detection
seo github <repo>      - GitHub repository optimization
seo plan <url>         - Strategic SEO planning
