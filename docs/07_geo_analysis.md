# Этап 7: GEO-анализ — Контур.Маркет в ИИ-ответах

> **Объект:** https://kontur.ru/market  
> **Дата:** апрель 2026  
> **GEO = Generative Engine Optimization** — оптимизация присутствия в ответах ИИ-систем  
> (ChatGPT, Perplexity, YandexGPT, Алиса, Google AI Overviews)

---

## 1. Что такое GEO и почему это важно

Традиционный SEO = попасть в список ссылок. GEO = попасть **в текст ответа**, который генерирует ИИ.

Когда пользователь спрашивает YandexGPT «посоветуй программу для кафе» — он не видит 10 ссылок. Он видит 1–3 названия, которые ИИ решил упомянуть. Всё, что не попало в ответ — не существует для этого пользователя.

**Доля запросов с AI-ответами в 2025–2026 гг.:**
- Google AI Overviews: ~40% запросов в США, распространяется в РФ
- Яндекс с YandexGPT: активно внедряется в поиск
- ChatGPT Search, Perplexity: растущая аудитория B2B-сегмента

## 3. Ключевая проблема: самоцитирование вместо цитирования

ИИ-системы формируют ответы на основе **независимых источников** — обзоров, рейтингов, экспертных статей. Собственные страницы продукта имеют низкий вес.

**Что происходит у Контур.Маркет:**

| Тип упоминания | Доля |
|---------------|------|
| Собственные статьи из `/spravka` | ~80% случаев появления |
| Независимые обзоры и рейтинги | ~20% |
| ИИ-рекомендации (ChatGPT, YandexGPT, Алиса) | 0% |

Это означает: когда ИИ формирует ответ из авторитетных источников — Контур.Маркет туда не попадает, потому что независимые источники его не упоминают в нужных категориях.

## 5. GEO-readiness: технический аудит

Чтобы ИИ мог «понять» и процитировать страницу, нужны структурированные данные и чёткая семантика.

| Фактор GEO-readiness | Статус | Влияние |
|---------------------|--------|---------|
| **Schema.org/SoftwareApplication** | ❌ нет | ИИ не идентифицирует продукт как ПО |
| **Schema.org/AggregateRating** | ❌ нет | Нет рейтинга в структурированном виде |
| **Schema.org/FAQ** | ❌ нет | Нет прямых ответов на вопросы |
| **Schema.org/Product** | ❌ нет | Тарифы не размечены как продукт |
| **Чёткий H1 с ключевым словом** | ⚠️ частично | ИИ использует H1 для идентификации темы |
| **Конкретные числа и факты** | ⚠️ мало | «50 000 клиентов», «с 2015 года» — нужны на страницах |
| **Ответы на вопросы в тексте** | ⚠️ в /spravka | На коммерческих страницах — нет |
| **Упоминания в независимых СМИ** | ⚠️ слабо | VC.ru, деловые издания — редко |
| **Экспертные цитаты / авторство** | ❌ нет | Нет E-E-A-T сигналов |

## 7. GEO-рекомендации

### 7.1 Немедленно (≤1 месяца)

**1. Добавить Schema-разметку на ключевые страницы:**

```json
// На главной /market и лендингах сегментов:
{
  "@type": "SoftwareApplication",
  "name": "Контур.Маркет",
  "applicationCategory": "BusinessApplication",
  "operatingSystem": "Web, Android, Windows",
  "offers": {
    "@type": "Offer",
    "price": "2500",
    "priceCurrency": "RUB"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.5",
    "reviewCount": "200"
  }
}
```

**2. Добавить FAQ Schema на страницы сегментов:**
- «Сколько стоит программа для кафе?» → ответ с ценой
- «Работает ли с ЕГАИС?» → ответ
- «Есть ли бесплатный период?» → ответ

Это прямо индексируется ИИ-системами как Q&A пары.

**3. Внести Контур.Маркет на Capterra и G2** — даже без активного продвижения, наличие профиля включает продукт в обучающие данные международных LLM.

### 7.2 Краткосрочно (1–3 месяца)

**4. Наполнить страницы конкретными фактами:**

ИИ цитирует конкретику, а не общие слова. Нужно добавить на страницы:
- «Более X клиентов используют Контур.Маркет» (число)
- «Работает в X регионах России»
- «Соответствует 54-ФЗ, ЕГАИС, требованиям Честного знака»
- «Средняя экономия времени на приёмке товара — 2–3 часа в неделю»

**5. Создать контент под запросы «альтернатива X»:**

Самый быстрый способ попасть в GEO-ответы — стать ответом на вопрос «что вместо iiko / YCLIENTS для малого бизнеса». Страницы:
- `/market/vs-iiko` — «Контур.Маркет как альтернатива iiko для малого кафе»
- `/market/vs-yclients` — «Контур.Маркет как альтернатива YCLIENTS»

Эти страницы не агрессивные — формат «в чём разница, кому что подойдёт».

**6. Работа с агрегаторами:**
- Увеличить число отзывов на OtzyvMarketing (сейчас 3 — ИИ игнорирует)
- Активно отвечать на отзывы на всех платформах (сигнал активности)
- Разобраться с платформой, где рейтинг 3.2/5 — выяснить источник негатива

### 7.3 Среднесрочно (3–6 месяцев)

**7. PR в отраслевых СМИ:**

ИИ-системы имеют высокий вес для материалов в:
- VC.ru — статьи от имени компании или партнёров
- РБК, Коммерсантъ (деловые разделы) — упоминания в обзорах
- Профильные HoReCa-издания (FoodService, Restoran.ru)
- Beauty-издания (Nails, Hair's How — если выходить в этот сегмент)

Цель: чтобы фраза «Контур.Маркет — программа для [кафе/салона]» встречалась в независимых авторитетных текстах, которые LLM индексируют.

**8. Экспертный контент с авторством:**

Google и Яндекс (при обучении LLM) доверяют контенту с явным авторством эксперта. Добавить в `/spravka` авторов с фото и должностью — это E-E-A-T сигнал, который влияет на вес контента при формировании AI-ответов.

**9. Яндекс ИИ-экосистема — специфика:**
- YandexGPT формирует ответы преимущественно из индексированных страниц Яндекса → приоритет: Яндекс.Бизнес профиль, Яндекс.Дзен статьи, высокий ИКС
- Алиса при ответах на бизнес-вопросы часто ссылается на Яндекс.Маркет и topсписки → нужно присутствие в агрегаторах с хорошим рейтингом

| Упоминания в деловых СМИ | Google Alerts / Brand Analytics | 2+ материала в месяц |
