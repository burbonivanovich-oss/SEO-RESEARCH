## 1. Анализ УТП и позиционирования

### 1.1 Текущее позиционирование Контур.Маркет

**Главный оффер:** «Зарабатывайте больше за счёт автоматизации учёта, кассы, ОФД, работы с клиентами и сотрудниками»

Это **функциональное**, а не **ценностное** позиционирование: перечисление технических компонентов вместо конкретного бизнес-результата. Слово «зарабатывайте больше» — правильное направление, но теряется на фоне перечисления модулей.

### 1.2 Сравнение УТП с конкурентами

| Продукт | Главный оффер | Акцент | Цена (от) |
|---------|--------------|--------|-----------|
| **Контур.Маркет** | «Зарабатывайте больше за счёт автоматизации учёта, кассы, ОФД...» | Перечисление функций | 2 500 ₽/3 мес |
| **МойСклад** | «Управляйте торговлей легко» + бесплатный тариф | Простота + нулевой порог входа | Бесплатно / от ~450 ₽/мес |
| **iiko** | «Всё под контролем: от кухни до кассы» | Полный контроль ресторана | Не раскрыто публично |
| **YCLIENTS** | «Забудьте о пустых окошках» | Потеря денег как ключевая боль | от 686 ₽/мес; 55 000 компаний |
| **Эвотор** | «Умная касса для вашего бизнеса» | Простота устройства | от 1 900 ₽/мес |
| **Business.ru** | «Автоматизация бизнеса от 500 руб/мес» | Цена — главный аргумент | от 500 ₽/мес |
| **Quick Resto** | «Облако для общепита — подключение за 5 минут» | Скорость старта | Не раскрыто |
| **Saby (Тензор)** | «Для бизнеса: CRM, касса, ЭДО в одном» | Экосистема, широта охвата | от 500 ₽/мес |

**Ключевые наблюдения:**

1. **YCLIENTS** бьёт по боли («пустые окошки» = деньги на ветер) — самая сильная формула в сегменте услуг. Имеет 55 000 компаний в базе — социальное доказательство прямо в оффере.
2. **МойСклад** снимает барьер входа бесплатным тарифом и заявляет «до 50% экономии». Контур.Маркет не имеет бесплатного тарифа и не говорит об экономии в цифрах.
3. **Quick Resto** берёт скоростью («за 5 минут») — для малого бизнеса это критичный аргумент.
4. **Контур.Маркет** не использует ни одну из этих стратегий на посадочных страницах сегментов.

## 2. Анализ конверсионной воронки

### 2.1 Типичный путь пользователя — розница

```
Запрос: «программа для розничного магазина»
    ↓
Посадочная: /market/roznitsa-loyalnost
    ↓
CTA: «Оставить заявку» ← основной вариант
    ↓
Форма: имя + телефон
    ↓
Ожидание звонка менеджера (часы / следующий рабочий день)
    ↓
Продажа по телефону
```

**Проблема:** модель «оставить заявку → звонок» создаёт трение. Пользователь, пришедший с поиска в сравнительном режиме, уходит к конкуренту, который даёт мгновенный доступ.

### 2.2 Типичный путь — сфера услуг

```
Запрос: «программа для салона красоты»
    ↓
Выдача: YCLIENTS (позиция 1–3), DIKIDI (4–5), Saby (6–7)
    ↓
Контур.Маркет /uslugi/salony-krasoty — не в топ-20
    ↓
Пользователь не видит Контур.Маркет ← потеря на этапе до клика
```

**Вывод:** в сегменте услуг воронка обрывается до клика — страница существует, но не видна. Проблема двойная: и SEO-видимость, и сила оффера.

### 2.3 Акция «14 дней бесплатно»

- Страница: `/market/actions/306`
- **Не является** основным CTA ни на одной из посадочных страниц
- Требует дополнительного клика, чтобы найти
- Условие: «ранее не использовал Маркет» — стандартное, но не всегда понятное новому пользователю
- Конкурентная проблема: МойСклад предлагает бесплатный тариф **без временного ограничения** → более сильный аргумент

### 2.4 Точки утечки трафика

| Точка | Проблема | Потери |
|-------|---------|--------|
| `/market/features` — title «Kontur» | Страница не видна в SERP | Весь трафик на раздел функций |
| `/market/capabilities/roznitsa` | Только форма, нет контента | Высокий % отказов |
| `/market/uslugi/salony-krasoty` | Не в топ-20 по целевым запросам | Потеря сегмента услуги красоты |
| `/market/obshepit-loyalnost/bar`, `/coffee-house` | Шаблонный тонкий контент | Нет трафика из поиска |
| Тарифы: `/price?period=3&count=1` | Параметрические дубли в индексе | Размытие PageRank |
| Региональные страницы: только 2 региона | 85 регионов без геотаргетинга | Потеря геотрафика |

## 4. Чеклист недостающих элементов по типам страниц

### Главные лендинги сегментов (`/roznitsa-loyalnost`, `/obshepit-loyalnost`, `/uslugi`)

- [ ] Meta description (отсутствует на всех)
- [ ] Блок «N клиентов уже используют» с числом
- [ ] Блок кейсов / отзывов с именем и городом бизнеса
- [ ] FAQ-блок под SEO (ответы на запросы «как», «сколько стоит», «чем отличается»)
- [ ] CTA «Попробовать 14 дней» как основная кнопка (не только «Оставить заявку»)
- [ ] Сравнительная таблица с конкурентами
- [ ] Видео-демо или скриншоты интерфейса

### Страницы подсегментов (`/cafe`, `/salony-krasoty`, `/avtoservisy`, `/bar`)

- [ ] Meta description
- [ ] Уникальный текстовый контент (сейчас — вероятно шаблонный)
- [ ] Специфичные для ниши боли и решения (не общие слова)
- [ ] Внутренние ссылки с родительской страницы сегмента
- [ ] Canonical-атрибут (риск дублирования между `/cafe` и `/coffee-house`)

### Страницы функций (`/features/*`)

- [ ] Meta description
- [ ] Блок «кому подходит» (розница / общепит / услуги)
- [ ] Ссылки на лендинги сегментов как related content
- [ ] Конкретные цифры результата («в 2–3 раза быстрее», «экономия X часов»)

### Тарифная страница

- [ ] Meta description
- [ ] Таблица сравнения тарифов без квиза (для сканирующего пользователя)
- [ ] Калькулятор или пример расчёта ROI
- [ ] Блок FAQ по тарифам («что будет после пробного периода», «можно ли сменить тариф»)
- [ ] Canonical на параметрические дубли `/price?period=…`

## 5. Итоговые выводы

**Топ-5 контентных проблем продукта:**

1. **Универсальная отсутствие meta description** — ни одна коммерческая страница не имеет оптимизированного описания. CTR из поиска снижен на всех страницах.

2. **Страницы подсегментов существуют, но «orphan»** — `/salony-krasoty`, `/bar`, `/coffee-house` не получают внутренних ссылок с родительских страниц, не оптимизированы, содержат тонкий шаблонный контент. Потенциал есть, реализации нет.

3. **Сломанный раздел `/market/features`** — title «Kontur» означает полное отсутствие трафика на хаб функций. Все подстраницы функций лишены «родителя» с нормальным PageRank.

4. **Конверсионная воронка с трением** — CTA «Оставить заявку» vs мгновенный доступ у конкурентов. В сегменте услуг это критично: YCLIENTS даёт демо без звонка.

5. **Нет социального доказательства нигде** — ни число клиентов, ни отзывы, ни кейсы не видны ни на одной из 15+ проанализированных страниц в SERP.
