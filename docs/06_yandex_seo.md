## 2. Яндекс-специфичные факторы ранжирования

### 2.1 ИКС (Индекс Качества Сайта)

ИКС — метрика Яндекса, отражающая «полезность» сайта для пользователей. Складывается из:
- Объём уникальных посетителей из Яндекса
- Поведенческие факторы (время на сайте, возвраты)
- Репутация в экосистеме (упоминания, ссылки)

**Оценка для Контур.Маркет:**
- kontur.ru — высокий ИКС (крупный федеральный бренд, многопродуктовый домен)
- Это **преимущество**: вся ссылочная масса kontur.ru работает на `/market`
- **Риск**: Яндекс может воспринимать `/market` как подраздел корпоративного сайта, а не самостоятельный продуктовый ресурс → слабее ранжирует по коммерческим продуктовым запросам

### 2.2 Поведенческие факторы (ПФ) — критический фактор Яндекса

Яндекс учитывает ПФ значительно сильнее Google:
- CTR в выдаче → низкий из-за слабых meta description
- Время на сайте / глубина → неизвестно, но CTA «оставить заявку» (без мгновенного доступа) повышает отказы
- Возврат к выдаче (pogo-sticking) → вероятно высокий на страницах без контента (`/capabilities/roznitsa`)

**Практический вывод:** улучшение meta description и контента страниц прямо влияет на ПФ → на позиции в Яндексе сильнее, чем в Google.

### 2.3 Региональность

Яндекс учитывает геопривязку бизнеса значительно строже Google:

| Фактор | Статус Контур.Маркет |
|--------|---------------------|
| Региональные страницы тарифов | Есть `/price/77` (Москва), `/price/66` (Екатеринбург) — **только 2 из 85 регионов** |
| Геотаргетинг в Яндекс.Вебмастере | Неизвестно (нет доступа) |
| Региональные представители | Дилерская сеть с отдельными сайтами (kontur165.ru, kontur-center.ru и др.) |
| Упоминания в региональных каталогах | Есть через дилеров |

**Проблема:** дилерские сайты с тарифами и описанием продукта могут **конкурировать с основным сайтом** в региональной выдаче Яндекса. Яндекс может предпочесть региональный сайт дилера для пользователя из Казани или Новосибирска.

**Рекомендация:** создать региональные страницы `/market/price/{код}` для топ-20 регионов по объёму бизнеса — это даст геотаргетинг без создания дилерских конфликтов.

### 2.4 Турбо-страницы

**Статус:** нет подтверждений, что Контур.Маркет использует Яндекс Турбо-страницы.

Турбо-страницы — облегчённые мобильные версии страниц, которые Яндекс загружает мгновенно из своего кэша. Показываются с иконкой ракеты в мобильной выдаче.

| Аспект | Оценка |
|--------|--------|
| Актуальность для продукта | Средняя — B2B SaaS редко нуждается в Турбо |
| Потенциал | Информационные страницы `/spravka` выиграли бы от Турбо |
| Приоритет | Низкий — другие задачи важнее |

### 2.5 Яндекс.Бизнес (бизнес-профиль)

Яндекс.Бизнес — аналог Google Business Profile. Карточка показывается в колдунщике при брендовых запросах.

**Что известно:**
- Конкуренты (YCLIENTS, МойСклад) активно используют Яндекс.Бизнес с отзывами
- Рейтинг в Яндекс.Бизнес формируется из 3–5+ отзывов и влияет на доверие
- Найдены отзывы на HF.ru (69 отзывов, 2025 г.) — часть, вероятно, агрегируется Яндексом

**Проблема:** если карточка Яндекс.Бизнес не заполнена или заполнена как «СКБ Контур», а не «Контур.Маркет» — брендовый трафик не получает структурированного представления.

## 3. Агрегаторы отзывов в Яндексе

По запросу «контур маркет отзывы» в топе — не официальный сайт, а агрегаторы:

| Площадка | Что показывает |
|---------|---------------|
| **Startpack** (startpack.ru) | Агрегированные оценки, сравнения с конкурентами |
| **Otzovik** (otzovik.com) | Пользовательские отзывы, часто негативные |
| **HF.ru** | 69 отзывов, 2025 г. — разбор функций |
| **OtzyvMarketing** | Экспертные и пользовательские оценки |
| **A2IS** | Технический каталог: цены, функции, обзор |

**Тональность отзывов (восстановлено):**
- ✅ Позитив: простой интерфейс, обновления под законодательство, поддержка в чате, учёт товаров
- ❌ Негатив: высокая цена, долгий ответ поддержки (>1 часа упоминается), опасения по деградации сервиса

**Яндекс-специфичная проблема:** агрегаторы с отзывами ранжируются выше официального сайта по запросам «отзывы» → Яндекс доверяет им как независимым источникам. Это двойной риск: негативные отзывы видны раньше официальной позиции компании.

## 6. Рекомендации, специфичные для Яндекса

### Немедленно (≤2 недели)

1. **Проверить и заполнить Яндекс.Бизнес** — убедиться, что карточка создана под брендом «Контур.Маркет», а не только «СКБ Контур». Добавить описание, фото интерфейса, категорию «Программное обеспечение».

2. **Мониторинг отзывов на агрегаторах** — настроить отслеживание Startpack, Otzovik, HF.ru. Официально ответить на негативные отзывы — Яндекс учитывает активность компании при формировании рейтинга.

3. **Добавить meta description** на все коммерческие страницы — в Яндексе это прямо влияет на CTR, а CTR влияет на ПФ и позиции.

### Краткосрочно (1–2 месяца)

4. **Schema-разметка:**
   - `FAQ` на страницах сегментов → потенциальные колдунщики в Яндексе
   - `AggregateRating` → звёздочки в сниппете → рост CTR
   - `BreadcrumbList` → структурированные хлебные крошки в сниппете

5. **Региональные страницы** — создать `/market/price/{код}` для топ-20 регионов (Москва уже есть, добавить: СПб, Екатеринбург, Новосибирск, Казань, Краснодар и др.). Это снизит конкуренцию с дилерскими сайтами и даст геотаргетинг в Яндексе.

6. **Устранить поведенческие риски:**
   - Добавить контент на `/capabilities/roznitsa` (сейчас — только форма, пользователь уходит)
   - Ускорить загрузку страниц (Яндекс учитывает скорость сильнее после 2023 г.)

### Среднесрочно (2–4 месяца)

7. **Контент-стратегия против r_keeper и YCLIENTS:** создать сравнительные страницы — «Контур.Маркет vs r_keeper для кафе», «Контур.Маркет vs YCLIENTS для салона». Яндекс хорошо ранжирует такие страницы по запросам «альтернатива X», «сравнение X и Y».

8. **Расширить `/spravka`** — информационный хаб уже работает хорошо. Добавить статьи по запросам, где конкуренты не представлены: «как автоматизировать кофейню», «учёт в барбершопе», «онлайн-запись для автосервиса».
