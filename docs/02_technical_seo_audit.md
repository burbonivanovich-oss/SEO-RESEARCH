## 2. Критические технические проблемы

### 2.1 🔴 /market/features — отсутствие Title

Страница `/market/features` (общий обзор всех возможностей) в поисковой выдаче показывается с тайтлом **«Kontur»** — это явный технический дефект: либо не прописан тег `<title>`, либо он генерируется динамически и не рендерится для поисковых роботов.

**Риск:** страница практически невидима в органике по информационным и коммерческим запросам о возможностях продукта.

### 2.2 🔴 Блокировка ботов (403 Forbidden)

Сайт возвращает 403 на все прямые HTTP-запросы от не-браузерных User-Agent'ов. 

**Возможные сценарии:**
- Блокировка происходит только для нестандартных UA (SEO-боты), а Googlebot/Яндексбот пропускаются — тогда это не критично для SEO
- Блокировка тотальная + рендеринг через JavaScript — тогда критично: нужен SSR или динамический рендеринг

**Что это значит:** если сайт на SPA/React без SSR и закрыт для ботов, поисковики видят пустую страницу. Проверить через: `Google Search Console → Проверка URL → Посмотреть страницу как Googlebot`.

### 2.3 ⚠️ Дублирование тарифных страниц

Обнаружены потенциальные дубли:

| Проблемная группа | URL-примеры | Риск |
|------------------|-------------|------|
| Тарифы по регионам | `/market/price`, `/market/price/77`, `/market/price/66` | Дублирование контента между регионами |
| Тарифы с GET-параметрами | `/market/price?period=3&count=1` | Параметрические дубли, попадающие в индекс |

Если страницы `/price/77` и `/price/66` отличаются только ценами — это сильный SEO-актив (региональные посадочные). Но если они полностью идентичны по шаблону — нужны canonical-теги, указывающие на «правильную» версию.

**Параметрический URL** `/market/price?period=3&count=1` в индексе — явная проблема: нужно либо `noindex`, либо canonical на `/market/price`.

### 2.4 ⚠️ Непоследовательный формат Title

В тайтлах используются два разных разделителя:
- `—` (тире): большинство страниц
- `|` (пайп): страницы `/market/kkt`, `/market/roznitsa-loyalnost`

Стандарт должен быть единым. Пайп чуть лучше работает на мобильных (короче), тире — традиционнее для Рунета.

### 2.5 ⚠️ Двойной бренд в Title

На страницах `/market/features/marking` и `/market/features/online`:
> «... через Контур.Маркет — Контур.Маркет»

Бренд дублируется, что «съедает» ~15 символов без пользы и выглядит неряшливо в выдаче.

## 4. Индексация

### 4.1 Количество страниц в индексе Google

Запрос `site:kontur.ru/market` возвращает ограниченное количество результатов (Google обрезает до 10 в сниппете). Реальное число индексированных страниц неизвестно без доступа к GSC.

**Оценка:** с учётом:
- ~10+ страниц оборудования `/kkt/*`
- ~5+ сегментных лендингов
- ~3 тарифных страниц
- `/spravka/` — потенциально 50–200+ статей (с числовыми ID)
- `/news/` — неизвестное количество

**Итого: предположительно 100–500 страниц** в зоне `/market/*`.

### 4.2 Поддомены продукта

| Поддомен | Назначение | SEO-статус |
|---------|-----------|-----------|
| `support.kontur.ru/market` | База знаний / справка поддержки | Индексируется, конкурирует с основным сайтом |
| `help.kontur.ru/market-cryptopro` | Диагностика | Индексируется |
| `install.kontur.ru/market` | Страница установки | Индексируется |
| `market.kontur.ru` | Приложение (SaaS) | Не для индексации |

**Риск:** `support.kontur.ru/market` и `kontur.ru/market/spravka` могут конкурировать между собой по информационным запросам (каннибализация).

## 5. Технический стек и рендеринг

### 5.1 Что известно

- Сайт отдаёт **403 для нестандартных UA** — характерно для JavaScript-приложений с защитой от скрапинга
- Мобильное приложение на React Native / нативный iOS + Android — не влияет на веб
- Конкур.ру в целом — большая платформа с разными продуктами, вероятно, микрофронтенды

### 5.2 Гипотеза о рендеринге

С большой вероятностью `/market` — **SPA на React** с SSR (Next.js или custom), поскольку:
- Страницы индексируются (тайтлы видны в выдаче)
- Поисковые сниппеты содержат осмысленный контент
- НО: страница `/market/features` с тайтлом «Kontur» — возможно, единственная страница с broken SSR/title-генерацией

## 7. HTTPS и базовая безопасность

- Домен `kontur.ru` работает на **HTTPS** (стандарт, не вызывает сомнений для крупного финтех-сервиса)
- SSL-сертификат: по данным из открытых источников — wildcard `*.kontur.ru`, выдан GlobalSign GCC R3 / RapidSSL
- Редирект HTTP→HTTPS: стандартный (предположительно работает корректно)
- Редирект www→без www (или наоборот): требует проверки

## 10. Что нельзя проверить без прямого доступа

Следующие параметры требуют доступа к **Яндекс Вебмастеру, Google Search Console** или SEO-инструментов с реальным браузером (Screaming Frog, Netpeak Spider):

- Точные показатели Core Web Vitals (LCP, CLS, INP)
- Наличие/отсутствие canonical-тегов на тарифных страницах
- Наличие hreflang (если есть языковые версии)
- Глубина вложенности страниц и internal PageRank
- Скорость рендеринга (TTFB, FCP)
- Полный список страниц в индексе
- Наличие/отсутствие sitemap.xml и его актуальность
