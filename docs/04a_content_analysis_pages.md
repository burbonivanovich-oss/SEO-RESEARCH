## 2. Реконструкция контента ключевых страниц

### 2.1 Главная страница `/market`

| Элемент | Восстановленный текст |
|---------|----------------------|
| **Title** | Автоматизация малого и среднего бизнеса — управление бизнесом через сервис |
| **Meta desc** | Решения для малого и среднего бизнеса в рознице, общепите и сфере услуг |
| **H1 / Hero** | «Зарабатывайте больше за счёт автоматизации учёта, кассы, ОФД, работы с клиентами и сотрудниками» |

Функциональные блоки на странице:

| Блок | Описание |
|------|----------|
| Касса | Для ПК, планшета, POS-терминала (Windows); мобильное приложение Android |
| Учёт товаров | Каталог, цены, ценники, остатки, управленческий учёт |
| ОФД | Передача в ФНС и Честный знак, соответствие 54-ФЗ |
| ЕГАИС | Накладные, акты, алкодекларации, помарочный учёт |
| Маркировка | Приёмка, продажа, интеграция с Честным знаком |
| Лояльность | База клиентов, акции, бонусы, SMS |
| Сотрудники | Расписание, загрузка персонала |

**SEO-проблема главной:** title не содержит ни одного коммерческого ключевого слова («касса», «программа для магазина», «учёт товаров»). Фраза «автоматизация малого и среднего бизнеса» конкурирует с тысячами нерелевантных сайтов.

---

### 2.2 Тарифная страница `/market/price-group` + `/market/price`

Квиз-механика: пользователь выбирает тип бизнеса → число точек → регион → попадает на `/price/{код региона}`.

**Восстановленные тарифы:**

| Тариф | Цена | Что включено |
|-------|------|-------------|
| **Базовый** | от 2 500 ₽/3 мес | Каталог, касса, неограниченное число пользователей и касс, поддержка чат + email |
| **Оптимальный** | от 4 600 ₽/3 мес | + Учёт остатков, приёмка накладных, телефонная поддержка |
| **Премиум** | от 7 400 ₽/3 мес | + Выделенная телефонная линия, приоритетная поддержка |

Дополнительные модули (продаются отдельно):
- ОФД — отдельный тариф
- ЕГАИС — подключается к любому тарифу
- Маркировка — надстройка
- Лояльность — включена в Оптимальный и Премиум

**Проблема индексации:** URL `/market/price?period=3&count=1` и аналогичные параметрические вариации попадают в индекс как дубли основной тарифной страницы. Canonical не настроен или игнорируется.

**Контентные пробелы тарифной страницы:**
- Нет сравнительной таблицы тарифов «на одном экране» без квиза
- Нет блока «что я получу за эти деньги» с конкретными примерами экономии
- Нет социальных доказательств (отзывы, число клиентов на тарифе)
- Нет калькулятора ROI («сколько сэкономите при переходе с Excel»)

### 2.3 Страница `/market/features/upr-uchet` — управленческий учёт

Восстановленный контент:

- Интеграция с **Контур.Пульс** — отдельный продукт SKB Kontur для управленческой аналитики; перекрёстная продажа внутри экосистемы
- Учёт доходов и расходов по категориям
- Аналитика прибыльности: отдельно по каждой точке продаж
- **ML-автокатегоризация** — система автоматически классифицирует операции по статьям бюджета
- Сравнение периодов: месяц к месяцу, год к году

**SEO-оценка страницы:**
- Title точный, ключ «управленческий учёт» присутствует ✅
- Аудитория двойная: розница + общепит + услуги → нет сегментации контента под разные интенты
- Конкурирует с «управленческий учёт в Excel», «1С управленческий учёт» — без явного аргумента «почему Маркет, а не 1С»

### 2.4 Страница `/market/features/debit` — загрузка накладных

Восстановленный контент (3-шаговый процесс):

1. **Сканировать** — загрузить скан бумажной накладной (PDF, PNG, JPG, TIF) или получить электронную через EDI/ЭДО
2. **Распознать** — AI распознаёт наименования товаров, количество, цены автоматически
3. **Принять** — товары поступают на остатки, документ сохраняется

**Заявленный результат:** приёмка в 2–3 раза быстрее по сравнению с ручным вводом.

**SEO-оценка страницы:**
- Функция нишевая, но практически значимая для розницы и общепита
- Запрос «загрузка накладных онлайн» — низкочастотный, конкуренция невысокая → хорошая возможность быть в топ-3
- Страница не продвигается как преимущество на главных лендингах сегментов

### 2.6 Страница `/market/uslugi/salony-krasoty`

Восстановленный контент:

| Функция | Описание |
|---------|----------|
| Онлайн-запись 24/7 | Клиент записывается через ссылку в соцсетях или на сайте |
| Автоматический календарь | Запись появляется в расписании мастера без участия администратора |
| Отчёты по выручке | Аналитика дохода по каждому сотруднику — контроль KPI |
| Визуальное расписание | Наглядная сетка записей: мастер, время, услуга |
| Скидки автоматом | Бонусы и скидки клиента применяются на кассе автоматически |

**SEO-проблемы страницы — критические:**

1. **По запросу «программа для салона красоты»** страница не появляется в топ-20. Топ занимают: YCLIENTS (55 000 компаний, от 686 ₽/мес), DIKIDI, Saby (Тензор).
2. **Нет meta description** — сниппет в выдаче формируется автоматически из текста страницы, выглядит обрезанным.
3. **Title слабый** — «Программа для салона красоты — Контур.Маркет» не содержит дифференцирующего аргумента. YCLIENTS использует «Забудьте о пустых окошках».
4. **Нет внутренних ссылок** с главной `/uslugi` на эту страницу в видимой зоне — страница фактически «orphan» внутри сайта.

### 2.7 Страница `/market/obshepit-loyalnost/coffee-house` и `/bar`

Страницы **существуют**, но крайне слабо видны в поиске.

Восстановленный контент (по аналогии с `/cafe`):
- Учёт ингредиентов / технологические карты
- Заказы из зала на кухню / бар
- Лояльность: бонусы, скидки
- Касса для ПК или планшета

**Проблема:** нет дифференцирующего контента между `/cafe`, `/coffee-house` и `/bar`. Вероятно, шаблонные страницы с минимальными текстовыми отличиями → риск дублирования контента и «тонкого» контента по меркам Яндекса/Google.
