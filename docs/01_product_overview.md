## 1. Что такое Контур.Маркет

**Контур.Маркет** — облачная учётная система для автоматизации малого и среднего бизнеса от компании **СКБ Контур**. Продукт совмещает в себе:

- Кассовую программу (совместима с 54-ФЗ)
- Товарный учёт (склад, остатки, закупки)
- Работу с госсистемами (ЕГАИС, Честный знак / маркировка, ГИС Меркурий)
- ОФД (Оператор фискальных данных)
- CRM / систему лояльности
- Управление персоналом

Позиционирование: **«зарабатывай больше — автоматизируй учёт»**. Пробный период — 14 дней бесплатно.

## 2. Целевая аудитория

| Сегмент | Описание |
|---------|----------|
| **Розница** | Продуктовые и непродуктовые магазины, алкомаркеты, точки с маркированными товарами |
| **Общепит** | Кафе, рестораны, столовые, кофейни |

## 4. Функциональность по сегментам

### 4.1 Розница
- Учёт товаров от поступления до продажи, контроль остатков
- Кассовая программа: ПК, планшет, POS-терминал, мобильное приложение (Android)
- Работа с принтерами чека, сканерами, весами
- Скидки (на товар / на чек), отложенные чеки, смешанная оплата, возвраты
- Маркировка в Честном знаке, ЕГАИС (для алкоголя), ГИС Меркурий
- Система лояльности (доступна на каждом тарифе)
- SMS-рассылки через интеграцию с SMS Aero

### 4.2 Общепит
- Технологические карты блюд (без ограничений по количеству и версиям)
- Автоматический расчёт КБЖУ по встроенному справочнику
- Расчёт себестоимости блюда и наценки
- Учёт остатков ингредиентов, готовых блюд и полуфабрикатов
- Приём заказов по столикам и гостям
- Пречек, разделение чека по гостям
- «Бегунки» в цеха
- Инвентаризация

### 4.3 Сфера услуг
- Онлайн-запись клиентов 24/7 (виджет для сайта и соцсетей)
- Журнал/Календарь записей
- Управление графиком сотрудников
- База клиентов + система лояльности
- Отраслевые подсегменты: салоны красоты, автосервисы, медицина, юристы

### 4.4 Общее для всех сегментов
- ОФД — передача данных в ФНС и Честный знак в соответствии с 54-ФЗ
- Управленческий учёт и аналитика продаж
- Облачное хранилище (доступ с любого устройства)
- Продажа оборудования (кассы, сканеры, терминалы, принтеры, весы)

| **МойСклад** | Розница, опт, e-comm | Облачный склад + продажи, более гибкий для e-com |

## 7. Отзывы пользователей — ключевые инсайты

### Плюсы (по отзывам на Startpack, hf.ru, otzovik.com)
- Большая товарная база, быстрое внесение номенклатуры
- Простота освоения и использования
- Облачная архитектура — доступ с любого устройства
- Хорошая работа с ЕГАИС и ветеринарными накладными (ВеТис)

### Минусы (боли пользователей)
- **Техподдержка:** частые жалобы — долгие ответы, нерешённые проблемы
- **Шаблоны ценников:** нет возможности создать собственный шаблон
- **Стоимость:** базовый тариф + модули (ЕГАИС и т.д.) складываются в ощутимую сумму
- **Работа со сроками годности:** неудобный интерфейс
- **Перемещение товаров** между точками — сложно
- **Интеграция с Контур.Эльба** — ограниченная (только данные ОФД для налогового учёта)

## 8. Выводы для следующих этапов анализа

1. Сайт закрыт от ботов (403 на всех страницах) — SEO-аудит потребует инструментов с реальным браузером или данных Яндекс Вебмастера / Search Console.
2. Структура сайта содержит **минимум 3 сегментных ветки** (розница / общепит / услуги) + каталог оборудования + тарифные страницы.
3. Тарифы региональные — страницы `/market/price/{region_code}` — это потенциально большой массив региональных посадочных страниц.
4. Конкуренты присутствуют во всех трёх сегментах с более специализированными решениями.
