## 1. Общий профиль продукта в SEO

### Сильные стороны
- **Бренд Контура** — высокое доверие в теме госсистем (ЕГАИС, маркировка, ОФД)
- **Контент-хаб `/spravka`** — активно ранжируется по информационным запросам
- **Страница касс `/kkt`** — сильная коммерческая страница с ценой в title
- **Региональные тарифные страницы** — правильная стратегия, требует масштабирования
- **Широкая продуктовая линейка** — покрывает 3 сегмента + оборудование + госинтеграции

### Слабые стороны
- Сайт блокирует SEO-ботов (403) — нельзя независимо контролировать краулинг
- Страница `/market/features` показывается в выдаче с title «Kontur» — критический баг
- Meta description отсутствует на большинстве страниц
- Общепит и услуги SEO-недоразвиты при наличии конкурентного продукта
- Нет социальных доказательств ни на одном лендинге
- CTA требует заявки вместо мгновенного старта

## 2. Ключевые метрики для отслеживания прогресса

## 5. Рекомендации: стратегические (3–12 месяцев)

### 5.1 Пересмотр CTA-логики

**Текущая воронка:** Лендинг → «Оставить заявку» → звонок менеджера → продажа  
**Проблема:** конкуренты дают мгновенный доступ, Контур требует ожидания

**Рекомендация:** добавить «быстрый вход» без звонка:
```
[Попробовать бесплатно] → регистрация за 2 поля → сразу в продукт
[Оставить заявку]       → для тех, кто хочет консультацию
```

**Ожидаемый эффект:** рост CR лендинга на 15–30% (типовой результат A/B тестов в SaaS).

---

### 5.2 Устранить каннибализацию страниц розницы

**Проблема:** `/market/capabilities/roznitsa` и `/market/roznitsa-loyalnost` конкурируют за одни запросы

**Решение — разграничить интенты:**

| Страница | Интент | Контент |
|---------|--------|---------|
| `/market/capabilities/roznitsa` | «Что умеет Контур.Маркет для розницы?» (изучение) | Функциональный обзор с демо-видео, без продажи |
| `/market/roznitsa-loyalnost` | «Купить/подключить программу для магазина» (покупка) | Коммерческий лендинг с ценой, тарифами, отзывами, CTA |

---

### 5.3 Добавить социальные доказательства на все лендинги

**Минимальный набор на каждой сегментной странице:**
- Количество клиентов («более X магазинов уже работают»)
- 2–3 отзыва с именем, городом, типом бизнеса
- Рейтинг в Google Play / App Store (4,3★ в RuStore — использовать)
- 1 логотип или кейс узнаваемой компании

---

### 5.4 Разрешить доступ для SEO-аудита

**Проблема:** сайт возвращает 403 для нестандартных User-Agent  
**Риск:** если Googlebot и Яндексбот тоже получают 403 — продукт невидим в поиске

**Действие:** проверить через:
- Google Search Console → «Проверка URL» → «Посмотреть как Google»
- Яндекс Вебмастер → «Проверка ответа сервера»

Если боты блокируются — это причина № 1 для немедленного исправления. Всё остальное вторично.

---

### 5.5 Создать посадочные страницы под конкурентный трафик

**Стратегия:** создать страницы вида «Контур.Маркет vs [конкурент]» или «Альтернатива [конкурент]»

| URL | Target | Аргумент |
|-----|--------|---------|
| `/market/vs-moysklad` | «альтернатива МойСклад» | ЕГАИС и маркировка в базе, не нужны аддоны |
| `/market/vs-evotor` | «альтернатива Эвотор» | Работает с любым оборудованием, не привязан к железу |
| `/market/vs-iiko` | «Контур.Маркет для малого общепита» | Нет переплаты за ненужные модули |

**Примечание:** этот формат требует аккуратной проработки — не агрессивного сравнения, а позиционирования Контур.Маркет как оптимального выбора для МСБ.

## 8. Финальное резюме

### Контур.Маркет в SEO — где сейчас

Продукт занимает **устойчивую нишу** в теме госсистем и оборудования, но **упускает основные коммерческие кластеры**: программы для кафе, ресторанов, салонов красоты, барбершопов — то есть именно те запросы, по которым ищут продукты как у Контур.Маркет.

Причина не в отсутствии продукта — функционал для этих сегментов **есть**. Причина в том, что страниц под эти запросы **нет или они слабо оптимизированы**.

### Главный вывод

> Контур.Маркет инвестировал в продукт для общепита и услуг, но не инвестировал в SEO-видимость этого продукта. Конкуренты (iiko, YCLIENTS) занимают эти ниши не потому что лучше — а потому что у них больше целевых страниц с нужными ключевыми словами.

### Три действия с наибольшим ROI

1. **Техника (быстро):** Исправить title `/features` + canonical параметров + meta description → +CTR в выдаче без затрат на контент
2. **Контент (средне):** 5–8 лендингов под подсегменты общепита и услуг → выход в топ по запросам, где сейчас нет позиций
3. **Масштаб (долго):** 30+ региональных тарифных страниц → долгосрочный геотрафик с высокой конверсией
